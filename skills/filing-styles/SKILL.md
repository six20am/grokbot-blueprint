# Filing styles

Six ways to file a workspace. For each, give the name, who it suits in one line, and a sample tree of six to ten lines. Substitute the owner's own workspaces into the samples.

## Military

Suits people who want one fixed home per function and never want to hunt.

```
1-admin/      contracts, insurance, bookkeeping
2-intel/      research, competitors, reference
3-ops/        the daily work, schedules, SOPs
4-supply/     vendors, purchases, inventory
5-plans/      forward planning
6-comms/      outbound, drafts, correspondence
```

## By stage

Suits almost anyone producing repeatable work. Folders follow the work itself.

```
1-intake/     what came in, unprocessed
2-production/ active work
3-delivery/   what went out
4-archive/    finished and quiet
```

## By client or project

Suits people whose work is a set of named jobs with the same shape each time.

```
clients/
  acme/
    brief/
    work/
    delivered/
  northwind/
    ...same three inside each
```

## PARA

Suits people who think in terms of how active something is, not what it is.

```
1-projects/   has a deadline and an end
2-areas/      ongoing responsibility, no end
3-resources/  reference, might be useful later
4-archive/    done or dead
```

## Numbered index

Suits people who want to find by number and hate nested folders.

```
10-19 admin
20-29 money
30-39 clients
40-49 products
50-59 reference
```

## By date

Suits work that is naturally chronological: logs, journals, records, sessions.

```
2026/
  01/
    the items from January
  02/
```

## What stays the same

The three layers work under every style. Only the folder names and nesting change:

1. A map at the root saying what lives where.
2. A router at the root saying which files a given kind of task needs.
3. A short notes file inside each workspace saying what to read for what.

If the owner already has folders, keep their structure and add the three layers on top. Reorganizing someone's files on the first day is the fastest way to lose them.
